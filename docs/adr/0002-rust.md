# geleider is written in Rust

geleider is one program that acts as the command-line tool, the always-on background process and the MCP server. It is written in Rust. The recommended alternative was TypeScript on Bun, chosen for familiarity and because the OpenCode plugin has to be TypeScript anyway; Rust was picked over it by preference. Rust gives the smallest, fastest-starting program, which matters because Harness hooks start it on every event and it runs all day beside CK3 on an 8 GB Mac. The OpenCode plugin stays a thin TypeScript shim that only calls the geleider program.

## Considered Options

- **TypeScript on Bun**: recommended, not chosen.
- **Swift**: macOS-only, and no GUI is planned that would make it worth the switch.
- **Go, Python**: Go was a middle ground nobody preferred; Python is slower to start on every hook and harder to ship as one program.
